# forge3D

Site de vitrine e orçamento para impressão 3D sob encomenda. Site estático (HTML, CSS e JS), sem servidor e sem build.

## Como abrir
Dê dois cliques em `index.html`. Funciona sem internet, exceto fontes e links externos.

## Editar
- `data/config.js`: número de WhatsApp, preço por grama, preço por hora e margem.
- `data/produtos.js`: catálogo de peças (nome, categoria, cor, emoji e preço base).

## Publicar
Site estático: pode ser hospedado no GitHub Pages (Settings → Pages → branch `main`, pasta `/root`).
